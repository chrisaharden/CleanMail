This is a python spam filter agent that runs in the command line, processing IMAP emails based on config files.
AFter reviewing emails against a whitelist and blacklist, it contacts an API with an LLM for further reviews on emails that matched either list.
Please add a "True"/"False" option in the command files that "SkipAI".  When true, the script just writes the same info as usual about email, but it prefixes the line with "SKIPPED:"
